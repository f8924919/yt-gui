# ドキュメントの改善
## 目的
以下のドキュメントの改善は開発の効率化(コード確認の手間を減らす)や品質の向上(デグレードがなくメンテナンスしやすいコードを出力する)ことを目的に行います。  
ドキュメントは主にclaude codeによって読み取り/編集されています。  
したがって、claude code自身による読みやすさを考慮して変更してください。※Sonnet4.6でも読みやすいように考慮して変更してください。
## CLAUDE.mdの改善
CLAUDE.mdの改善方針について以下に記載します。ほかにも改善点がある場合には提案してください。
- このファイルに記載される内容としては、プロジェクト全体に関わるルール、プロジェクト自体の概要、開発で特によく使うコマンドなどの内容にしたいです。
- 仕様頻度の低い内容や詳細な記述はdocs以下に記載したいです。
- ファイル/ディレクトリの追加が必要であれば、実施してください。
- 入出力は日本語、思考は英語で行うように記載を追加してほしい。
## docsの改善
- claude code自身にとって読みやすく、コード変更時の仕様確認などが行いやすいように変更点がないか確認してください。
- 毎回、docs全体を読むのではなく必要な部分を参照できるようにdocsやCLAUDE.mdの構成を考えてください。
- ※重要 : コード変更の際にデグレードなどが起こりずらいように考慮してください。

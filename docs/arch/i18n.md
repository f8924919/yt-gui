# yt_gui/i18n.py

> 関連仕様: [多言語対応](../spec/i18n.md)

多言語対応モジュール。

## 公開 API

| 関数 | シグネチャ | 説明 |
|------|-----------|------|
| `set_language` | `(lang: str) -> None` | アクティブ言語を切り替える |
| `t` | `(key: str) -> str` | 翻訳文字列を返す |

`t(key)` のフォールバック順: アクティブ言語 → 日本語 → キー名そのまま。

## 内部構造

- `_LANGUAGES: dict[str, dict[str, str]]` — 言語コード → 文字列辞書のマップ
- 初期言語は `"ja"`
- 新言語を追加する手順は [locales.md](locales.md) 参照

## 定数

- `AVAILABLE_LANGUAGES: list[str]` — サポート言語コードのリスト（UI のコンボに使用）

# 設定ダイアログ

[← 目次](../index.md)

> 関連実装: [yt_gui/settings_dialog.py](../../arch/settings_dialog.md)

## 概要

`SettingsDialog(QDialog)` が実装するモーダルダイアログです。`ファイル > 設定...`（Ctrl+,）で開きます。設定変更はメインウィンドウを閉じずに適用されます。

**サイズ**: 520 × 520 px（固定）

---

## タブ構成

### 一般タブ

| 項目 | 種別 | 説明 |
|---|---|---|
| 保存フォルダ | テキスト入力 + 参照ボタン | ダウンロード先ディレクトリ。空欄の場合は `~/Downloads` を使用 |
| Cookies | ラジオボタン切り替え | 下記「Cookies 設定」を参照 |
| 言語 | コンボボックス | 日本語 / English |

#### Cookies 設定

3 択のラジオボタンで Cookies の取得方法を切り替えます。選択に応じて詳細 UI を表示します。

| 選択肢 | 追加表示 UI | 動作 |
|---|---|---|
| 使用しない | なし | Cookies を使用しない |
| ファイルを指定 | ファイルパス入力 + 参照ボタン | 指定した `.txt` ファイルを Cookies として使用 |
| ブラウザから取得 | ブラウザ選択コンボボックス | 指定ブラウザの Cookies を yt-dlp が自動取得 |

対応ブラウザ（全プラットフォーム共通）: Brave, Chrome, Chromium, Edge, Firefox, Opera, Vivaldi, Whale

macOS のみ Safari を追加で選択可能。

---

### 画質・音質タブ

| 項目 | 選択肢 | 対象形式 | 説明 |
|---|---|---|---|
| 解像度上限 | 480p / 720p / 1080p / 1440p / 2160p | *N*p 形式 | 映像の最大解像度 |
| 動画コンテナ | MP4 / MKV / WebM | 最高画質・*N*p・オリジナル形式（コンテナ結合時） | 出力コンテナ形式 |
| 音声形式 | MP3 / FLAC | MP3/FLAC 形式 | 音声抽出形式 |
| MP3 ビットレート | 128 / 192 / 256 / 320 kbps | MP3 形式のみ | MP3 抽出時のビットレート |

- 音声形式を FLAC にすると MP3 ビットレートの行が非表示になります
- タブの注記: 「最高画質」と「オリジナルの形式」には解像度・コンテナ設定は影響しません

> **注意**: 「最高画質」形式はコンテナ設定を反映しますが、解像度上限は適用されません。「オリジナルの形式」はコンテナ設定を出力形式ラジオボタンで個別に制御します。

---

### ファイル名タブ

yt-dlp の OUTPUT TEMPLATE 機能でダウンロードファイル名を設定する。

| 項目 | 種別 | 説明 |
|---|---|---|
| 単独動画 | テキスト入力 + 挿入メニュー + プレビュー | 単独動画 URL の保存名テンプレート |
| プレイリスト | テキスト入力 + 挿入メニュー + プレビュー | プレイリスト要素の保存名テンプレート（`%(playlist_title)s` を含めるとサブフォルダ自動作成） |
| デフォルトに戻す | ボタン | 両入力欄を既定値に戻す |
| 公式ドキュメントを開く | ボタン | yt-dlp の README OUTPUT TEMPLATE セクションをブラウザで開く |

#### 挿入できるフィールド

挿入メニューと「よく使うフィールド」凡例から選べる主要な変数:

| 変数 | 意味 |
|---|---|
| `%(title)s` | 動画タイトル |
| `%(uploader)s` | 投稿者 |
| `%(upload_date)s` | 投稿日 (YYYYMMDD) |
| `%(playlist_title)s` | プレイリスト名 |
| `%(playlist_index)s` | プレイリスト内番号 |
| `%(playlist_index)03d` | プレイリスト内番号 (3桁ゼロ埋め) |
| `%(ext)s` | 拡張子（必須） |

高度な変数（`%(release_date>%Y-%m-%d)s` などの拡張構文）は公式ドキュメントを参照してください。

#### 既定値

| 項目 | 既定値 |
|---|---|
| 単独動画 | `%(title)s.%(ext)s` |
| プレイリスト | `%(playlist_title)s/%(playlist_index)03d - %(title)s.%(ext)s` |

#### バリデーション

- `%(ext)s` が含まれない場合は保存時に警告ダイアログを表示し、ファイル名タブに切り替えて保存を中断する
- 構文エラー（`%` 記法の不正）も同様に警告で中断する

---

### プロキシタブ

yt-dlp の通信に使うプロキシを設定する。設定値は yt-dlp の `proxy` オプションとして `scheme://[user[:password]@]host[:port]` 形式に組み立てられ、メタデータ取得・形式取得・ダウンロード本体すべてに適用される。

| 項目 | 種別 | 説明 |
|---|---|---|
| プロキシを有効にする | チェックボックス | OFF のとき他の項目は入力可能だが無効化（グレーアウト）し、保存しても yt-dlp には反映されない |
| プロトコル | コンボボックス | `http` / `https` / `socks4` / `socks5` / `socks5h` |
| ホスト | テキスト入力 | プロキシのホスト名または IP（例: `proxy.example.com`） |
| ポート | テキスト入力（数値のみ） | 1〜65535。空欄可（プロトコル既定ポートを使う場合） |
| ユーザー名 | テキスト入力 | 認証付きプロキシのユーザー名。空欄可 |
| パスワード | テキスト入力（マスク表示） | 認証付きプロキシのパスワード。空欄可。設定ファイルに平文で保存される |

#### バリデーション

- 「プロキシを有効にする」が ON でホストが空欄の場合は保存時に警告ダイアログを表示し、プロキシタブに切り替えて保存を中断する
- ポートが 1〜65535 の範囲外、または数値以外の場合は同様に警告で中断する（QIntValidator により入力段階でも数値に制限される）

#### URL 組み立て規則

- `proxy_enabled=False` または `proxy_host` が空のときは yt-dlp に `proxy` オプションを渡さない
- ユーザー名・パスワードは `urllib.parse.quote(..., safe="")` でパーセントエンコードされる（`@` や `:` を含むパスワードに対応）
- ポート未入力時はホスト直後の `:port` を省略する

## 保存・キャンセルボタン

| ボタン | 動作 |
|---|---|
| 保存 | 設定を JSON ファイルに保存してダイアログを閉じる |
| キャンセル | 変更を破棄してダイアログを閉じる |

---

## 設定変更後のメインウィンドウへの反映

設定ダイアログを閉じると（保存時のみ）、`App` 側で以下を更新します。

| 変更項目 | 反映処理 |
|---|---|
| 保存フォルダ | `Downloader.output_dir` を更新 |
| 解像度上限 | `Downloader.video_resolution` を更新 |
| MP3 ビットレート | `Downloader.mp3_bitrate` を更新 |
| 動画コンテナ・音声形式 | 形式コンボボックスの表示名を再生成 |
| OUTPUT TEMPLATE | `Downloader.output_template_video` / `output_template_playlist` を更新（次のダウンロードから反映） |
| プロキシ | `build_proxy_url()` で組み立てた URL を `Downloader.proxy_url` に設定（次のダウンロードから反映） |
| 言語 | `i18n.set_language()` を呼び出し、UI 全体を即時再翻訳（再起動不要） |

既存のキューアイテムは追加時の設定のスナップショットでダウンロードされます（設定変更後も変わりません）。

# メインウィンドウ

[← 目次](../index.md)

> 関連実装: [yt_gui/app.py](../../arch/app.md)

## 概要

`App(QMainWindow)` が実装するメインウィンドウです。URL 入力・形式選択・キュー操作・ダウンロード実行をすべて 1 画面で行います。

---

## ウィンドウサイズ

オリジナル形式の詳細設定は別画面（[オリジナル形式ダイアログ](original-format-dialog.md)）に分離されているため、メインウィンドウの高さは形式選択によって変化しません（固定）。

| 状態 | サイズ |
|---|---|
| 既定 | 760 × 480 px |
| 最小サイズ | 560 × 380 px |

---

## レイアウト構成

```
┌─────────────────────────────────────────┐
│ メニューバー（ファイル）                     │
├─────────────────────────────────────────┤
│ 動画URL: [___________________________]  │
│ 形式選択: [▼ 最高画質 (MP4に結合)    ]  │
│                                         │
│ [詳細設定...] ← オリジナル形式選択時のみ表示│
│ [サムネイル埋め込みチェック] ← MP3時のみ  │
│ ☑ 区間を指定 開始[__] 終了[__] ☐再ｴﾝｺｰﾄﾞ │
│                                         │
│ [追加]  [キャンセル]                     │
├─────────────────────────────────────────┤
│ ┌── ダウンロードキュー ────────────────┐ │
│ │ # │ タイトル │ 形式 │ 状態         │ │
│ │ 1 │ ...      │ ...  │ 待機中       │ │
│ │ ...                               │ │
│ │ [ダウンロード開始] [削除]            │ │
│ └──────────────────────────────────┘ │
├─────────────────────────────────────────┤
│ ステータスラベル          [■■■□□□□□] │
└─────────────────────────────────────────┘
```

URL / 形式選択 / 追加ボタンを含む上部エリアは sizeHint で固定高、ダウンロードキュー領域が残りの縦スペースを伸縮して埋める単純な縦レイアウト（`QVBoxLayout`）です。オリジナル形式の詳細設定を別画面（[オリジナル形式ダイアログ](original-format-dialog.md)）へ分離して上部エリアが固定高になったため、旧 `QSplitter`（上部とキューの高さ比をドラッグ調整）は廃止されました。

## メニューバー

`ファイル` メニューのみ存在します。

| メニュー項目 | ショートカット | 動作 |
|---|---|---|
| 設定... | Ctrl+, | 設定ダイアログを開く（モーダル） |
| ログ表示 | — | ログダイアログを開く（非モーダル） |
| 終了 | — | アプリを閉じる（macOS では非表示） |

---

## URL 入力フィールド

- 単独動画 URL、プレイリスト URL の両方を受け付けます
- 編集モード中は読み取り専用になります
  - 単一アイテム編集時: そのアイテムの URL を表示
  - 複数アイテム編集時: `{count} 件を選択中` を表示

---

## 形式選択コンボボックス

設定値に応じて表示名が動的に変わります。

| 内部キー | 表示例 |
|---|---|
| `fmt_best_mp4` | 最高画質（MP4 に結合） |
| `fmt_720p` | 720p（MP4 に結合） |
| `fmt_mp3` | MP3（音声のみ・192kbps） |
| `fmt_original` | オリジナルの形式 |

- 音声形式が FLAC の場合、`fmt_mp3` の代わりに `FLAC（音声のみ）` を表示
- 複数アイテム編集モード中は「オリジナルの形式」がグレーアウトして選択不可

---

## 区間指定フィールド（ダウンロード範囲）

動画の一部分だけを切り出してダウンロードするための入力欄です（[区間ダウンロード](../features/download-behavior.md#区間ダウンロード)）。形式選択に依存せず常に表示され、すべての形式で利用できます。

| 要素 | 説明 |
|---|---|
| 区間を指定（チェック） | オンにすると下記の入力群を表示します。オフ（既定）のときは入力群を隠し、区間指定なしで通常どおりダウンロードします。 |
| モード（ラジオ: 時間範囲 / チャプター名） | 指定方法の切り替え（**排他**・既定は「時間範囲」）。選択中モードの入力欄だけを表示します。 |
| 開始 / 終了（時間範囲モード） | ダウンロードする時間範囲。`HH:MM:SS` / `MM:SS` / 秒数で入力します。 |
| チャプター名（チャプター名モード） | チャプタータイトルにマッチさせる正規表現（`re.search`・部分一致）。マッチした各チャプターを個別ファイルに切り出します（[区間ダウンロード — チャプター名モード](../features/download-behavior.md#指定方法チャプター名モード)）。 |
| 正確な区間でカット（再エンコード） | カット境界を再エンコードして指定時刻に正確に合わせます（既定オフ＝キーフレーム境界で高速・無劣化）。両モード共通。 |

### 入力検証

チェックがオンのとき、`追加` / `変更` の実行時に選択中モードに応じて以下を検証します。不正な場合は警告を表示し、追加・変更を行いません。

- **時間範囲モード**: 開始・終了がいずれも時刻として解釈できること（空欄不可）。開始 < 終了 であること。
- **チャプター名モード**: 入力が正規表現としてコンパイル可能であること（`re.compile`）。空欄不可。

### プレイリスト・複数編集時の扱い

- **プレイリスト**: 区間はプレイリストに適用できません。URL 入力時点では単一動画かプレイリストか判定できないため、タイトル取得後にプレイリストと判明し区間指定がある場合は警告を表示して追加を中断します（オリジナル形式 × プレイリストと同じ後追いバリデーション）。
- **複数アイテム編集中**: 1 つの区間指定を複数の異なる動画へ適用するのは無意味なため、区間 UI を無効化（グレーアウト）します（両モード共通）。

### 編集モードでの復元

単一アイテムの編集モードに入ると、そのアイテムの区間設定（モード / 開始 / 終了 / チャプター名 / 再エンコード）を UI に復元し、再編集できます。

### キューのツールチップ

キューアイテムのツールチップには、時間範囲モードでは `開始〜終了`、チャプター名モードでは入力した正規表現パターンを表示します。

## 詳細設定ボタン（オリジナル形式選択時）

形式コンボで「オリジナルの形式」を選択しているときだけ表示されるボタンです。クリックすると [オリジナル形式ダイアログ](original-format-dialog.md) を開きます。

- URL 入力欄が空のときは警告（`warn_no_url`）を表示し、ダイアログは開きません。
- オリジナル形式の **キューへの追加・編集適用はこのダイアログ内のボタンで行います**。そのため下記「追加 / 変更ボタン」はオリジナル形式選択時には非表示（または無効）になります。

## 追加ボタン / 変更ボタン

オリジナル形式**以外**の形式で使用します（オリジナル形式時はダイアログ側で追加/変更を行うため非表示）。

| 状態 | ボタンラベル | 動作 |
|---|---|---|
| 通常 | 追加 | URL をキューに追加（バックグラウンドでタイトル取得） |
| タイトル取得中 | 取得中... | 無効化、取得完了後に自動復帰 |
| 編集モード | 変更 | 選択アイテムの形式を更新してキューに戻す |

編集モード中は `キャンセル` ボタンも表示されます。

### 編集モードとオリジナル形式

編集モード中も形式コンボで形式タイプを切り替えられます。編集対象の形式が「オリジナルの形式」になっている場合は、上記「変更」ボタンの代わりに **「詳細設定...」ボタン**が表示され、ダイアログを編集モードで開いて「変更」を適用します。`App` は対象アイテムの `orig_settings` をダイアログへ渡し、ダイアログ側で復元 + フォーマット取得を行います（[オリジナル形式ダイアログ — 起動フロー（編集）](original-format-dialog.md)）。`キャンセル` ボタンはメインウィンドウ側に残ります。

## ダウンロードキュー

4 列のツリーウィジェットです。複数選択可能（Ctrl+クリック / Shift+クリック）で、修飾キーなしの左クリックで選択済み行を再クリックするとその行のみ選択解除されます。

| 列 | 内容 | 幅 |
|---|---|---|
| # | 追加順の連番 | 36px（固定） |
| タイトル | 動画タイトル（45文字超で末尾省略） | 伸縮 |
| 形式 | ダウンロード形式の表示名 | 140px（固定） |
| 状態 | 待機中 / ダウンロード中 / ✅ 完了 / ❌ エラー / ✏️ 編集中 | 120px（固定） |

### 状態の色

| 状態 | 文字色 |
|---|---|
| ダウンロード中 | `#1565c0`（青） |
| 完了 | `#2e7d32`（緑） |
| エラー | `#c62828`（赤） |
| 編集中 | `#e65100`（オレンジ） |
| 待機中 | デフォルト（テーマ依存） |

### ツールチップ

キューアイテムにマウスオーバーすると HTML ツールチップを表示します。

| 項目 | 表示条件 |
|---|---|
| サムネイル（240×135px） | サムネイル URL があり、バックグラウンド取得が完了している場合 |
| タイトル | 常に表示 |
| URL | 常に表示 |
| プレイリスト名 | プレイリストからの追加アイテムのみ |
| 字幕設定 | 字幕が選択されている場合 |
| 区間 | 区間（開始〜終了）が指定されている場合 |
| アーカイブ無視 | [アーカイブを無視して再取得](../features/download-behavior.md#アイテム単位でアーカイブを無視して再取得)が有効なアイテムのみ |
| 形式仕様 | オリジナル形式アイテムのみ |

### 右クリックコンテキストメニュー

| メニュー項目 | 有効条件 | 動作 |
|---|---|---|
| URL をコピー | 常に有効 | 選択アイテムの URL をクリップボードへ（複数時は改行区切り） |
| 形式を変更... | 待機中のアイテムが選択されており、編集モードでない | 編集モードに移行 |
| アーカイブを無視して再取得 | ダウンロードアーカイブが有効、待機中のアイテムが選択、編集モードでない | 当該アイテムを archive 照合・スキップの対象外にする（[ダウンロード動作](../features/download-behavior.md#アイテム単位でアーカイブを無視して再取得)） |

### キューボタン

| ボタン | 表示条件 | 動作 |
|---|---|---|
| ダウンロード開始 | ワーカー未実行時 | 待機中アイテムのダウンロードを開始 |
| 一時停止 | ワーカー実行中 | 現在処理中のアイテム完了後に停止 |
| 削除 | 常に表示 | 選択アイテムを削除（ダウンロード中・編集中は不可） |

## ステータスバー

ウィンドウ下部に常時表示されます。

- **ステータスラベル**: 現在の状態を文字で表示（例: 待機中は `準備完了`、走行中は全体進捗 `完了 3/10`）
- **プログレスバー**: 最大幅 160px。**キュー全体の進捗**（完了数 / 総数）を 0〜100% で表示する。テキスト非表示。同時ダウンロード（[設定 — ダウンロードタブ](settings-dialog.md#ダウンロードタブ)）で `N>1` のときは個々のアイテム進捗ではなく全体の完了割合を示す（個々の進捗はキュー各行に表示）。

> 個別アイテムの進捗（%）は**キューの各行のステータス列**に「ダウンロード中 45.2%」として表示する（[ダウンロードキュー — 行単位の進捗表示](../features/queue.md#行単位の進捗表示)）。

## 起動時の動作

1. 設定を読み込んで言語を設定
2. `~/cookies.txt` が存在し Cookies が未設定の場合、デフォルト Cookies として自動設定
3. ウィジェットを構築
4. `QTimer.singleShot(0, ...)` で依存ツール（ffmpeg・ffprobe・deno）の存在チェック。不足があれば警告ダイアログを表示

# メインウィンドウ

[← 目次](../index.md)

> 関連実装: [yt_gui/app.py](../../arch/app.md)

## 概要

`App(QMainWindow)` が実装するメインウィンドウです。URL 入力・形式選択・キュー操作・ダウンロード実行をすべて 1 画面で行います。

---

## ウィンドウサイズ

| 状態 | サイズ |
|---|---|
| 通常（オリジナル形式パネル非表示） | 560 × 480 px |
| オリジナル形式選択時（パネル展開） | 560 × 820 px |
| 最小サイズ | 560 × 380 px |

---

## レイアウト構成

```
┌─────────────────────────────────────────┐
│ メニューバー（ファイル）                     │
├─────────────────────────────────────────┤
│ 動画URL: [___________________________]  │
│ 形式選択: [▼ 最高画質 (MP4に結合)    ]  │
│                                         │
│ [オリジナル形式パネル] ← 形式選択時のみ表示│
│ [サムネイル埋め込みチェック] ← MP3時のみ  │
│                                         │
│ [追加]  [キャンセル]                     │
│                                         │
│ ┌── ダウンロードキュー ────────────────┐ │
│ │ # │ タイトル │ 形式 │ 状態         │ │
│ │ 1 │ ...      │ ...  │ 待機中       │ │
│ │ ...                               │ │
│ │ [ダウンロード開始] [削除]            │ │
│ └──────────────────────────────────┘ │
├─────────────────────────────────────────┤
│ ステータスラベル          [■■■□□□□□] │
└─────────────────────────────────────────┘
```

## メニューバー

`ファイル` メニューのみ存在します。

| メニュー項目 | ショートカット | 動作 |
|---|---|---|
| 設定... | Ctrl+, | 設定ダイアログを開く（モーダル） |
| ログ表示 | — | ログダイアログを開く（非モーダル） |
| 終了 | — | アプリを閉じる（macOS では非表示） |

---

## URL 入力フィールド

- 単独動画 URL、プレイリスト URL の両方を受け付けます
- 編集モード中は読み取り専用になります
  - 単一アイテム編集時: そのアイテムの URL を表示
  - 複数アイテム編集時: `{count} 件を選択中` を表示

---

## 形式選択コンボボックス

設定値に応じて表示名が動的に変わります。

| 内部キー | 表示例 |
|---|---|
| `fmt_best_mp4` | 最高画質（MP4 に結合） |
| `fmt_720p` | 720p（MP4 に結合） |
| `fmt_mp3` | MP3（音声のみ・192kbps） |
| `fmt_original` | オリジナルの形式 |

- 音声形式が FLAC の場合、`fmt_mp3` の代わりに `FLAC（音声のみ）` を表示
- 複数アイテム編集モード中は「オリジナルの形式」がグレーアウトして選択不可

---

## 追加ボタン / 変更ボタン

| 状態 | ボタンラベル | 動作 |
|---|---|---|
| 通常 | 追加 | URL をキューに追加（バックグラウンドでタイトル取得） |
| タイトル取得中 | 取得中... | 無効化、取得完了後に自動復帰 |
| 編集モード | 変更 | 選択アイテムの形式を更新してキューに戻す |

編集モード中は `キャンセル` ボタンも表示されます。

---

## ダウンロードキュー

4 列のツリーウィジェットです。複数選択可能（Ctrl+クリック / Shift+クリック）で、修飾キーなしの左クリックで選択済み行を再クリックするとその行のみ選択解除されます。

| 列 | 内容 | 幅 |
|---|---|---|
| # | 追加順の連番 | 36px（固定） |
| タイトル | 動画タイトル（45文字超で末尾省略） | 伸縮 |
| 形式 | ダウンロード形式の表示名 | 140px（固定） |
| 状態 | 待機中 / ダウンロード中 / ✅ 完了 / ❌ エラー / ✏️ 編集中 | 120px（固定） |

### 状態の色

| 状態 | 文字色 |
|---|---|
| ダウンロード中 | `#1565c0`（青） |
| 完了 | `#2e7d32`（緑） |
| エラー | `#c62828`（赤） |
| 編集中 | `#e65100`（オレンジ） |
| 待機中 | デフォルト（テーマ依存） |

### ツールチップ

キューアイテムにマウスオーバーすると HTML ツールチップを表示します。

| 項目 | 表示条件 |
|---|---|
| サムネイル（240×135px） | サムネイル URL があり、バックグラウンド取得が完了している場合 |
| タイトル | 常に表示 |
| URL | 常に表示 |
| プレイリスト名 | プレイリストからの追加アイテムのみ |
| 字幕設定 | 字幕が選択されている場合 |
| 形式仕様 | オリジナル形式アイテムのみ |

### 右クリックコンテキストメニュー

| メニュー項目 | 有効条件 | 動作 |
|---|---|---|
| URL をコピー | 常に有効 | 選択アイテムの URL をクリップボードへ（複数時は改行区切り） |
| 形式を変更... | 待機中のアイテムが選択されており、編集モードでない | 編集モードに移行 |

### キューボタン

| ボタン | 表示条件 | 動作 |
|---|---|---|
| ダウンロード開始 | ワーカー未実行時 | 待機中アイテムのダウンロードを開始 |
| 一時停止 | ワーカー実行中 | 現在処理中のアイテム完了後に停止 |
| 削除 | 常に表示 | 選択アイテムを削除（ダウンロード中・編集中は不可） |

---

## ステータスバー

ウィンドウ下部に常時表示されます。

- **ステータスラベル**: 現在の状態を文字で表示（例: `⬇️ ダウンロード中: 45.2% | 速度: 2.5MB/s | 残り: 12s`）
- **プログレスバー**: 最大幅 160px。ダウンロード進捗を 0〜100% で表示。テキスト非表示

---

## 起動時の動作

1. 設定を読み込んで言語を設定
2. `~/cookies.txt` が存在し Cookies が未設定の場合、デフォルト Cookies として自動設定
3. ウィジェットを構築
4. `QTimer.singleShot(0, ...)` で依存ツール（ffmpeg・ffprobe・deno）の存在チェック。不足があれば警告ダイアログを表示

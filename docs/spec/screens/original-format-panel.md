# オリジナル形式パネル

[← 目次](../index.md)

> 関連実装: [yt_gui/original_format_panel.py](../../arch/original_format_panel.md)

## 概要

`OriginalFormatPanel(QGroupBox)` が実装するパネルです。メインウィンドウの形式コンボで「オリジナルの形式」を選択すると表示されます（それ以外では非表示）。

動画の実際の映像・音声・字幕トラック一覧を yt-dlp で取得し、個別に選択してダウンロードできます。

---

## レイアウト構成

```
┌── オリジナル形式の詳細設定 ────────────────────────────────┐
│ 映像: [▼ 自動 (最良を選択)]              [形式を取得]    │
│ 音声:                     字幕:                          │
│ ┌──────────────────────┐ ┌────────────────────────────┐  │
│ │ 自動 (最良を選択)    │ │ ja - 日本語 [srt, vtt]     │  │
│ │ ダウンロードしない   │ │ en - English [srt, vtt]    │  │
│ │ opus (webm) [251] ja │ │ ja(自動生成) [vtt]         │  │
│ │ aac  (m4a)  [140] en │ │                            │  │
│ └──────────────────────┘ └────────────────────────────┘  │
│                          [▼ best] [MP4に埋め込む]        │
│ 出力: ● MP4 に結合   ○ remux のみ   ○ 音声のみ (MP3 192kbps) │
│ □ サムネイルを埋め込む  ☑ メタデータ  ☑ チャプター      │
└──────────────────────────────────────────────────────────┘
```

音声と字幕は左右 2 カラムで配置し、埋め込みオプション 3 つは 1 行に並べて縦圧迫を抑えています。

---

## 形式取得フロー

1. URL 入力欄に URL を入力
2. 「形式を取得」ボタンをクリック（またはキューアイテムの編集モード開始時に自動実行）
3. バックグラウンドスレッドで `Downloader.fetch_formats()` を呼び出す
4. 取得中は「取得中...」と表示してボタン・コンボを無効化
5. 取得完了後、映像・音声・字幕コンボ/リストに結果を反映

### エラー時

| 原因 | 表示 |
|---|---|
| プレイリスト URL を入力した | 警告ダイアログ（単独 URL を指定するよう案内） |
| その他エラー | エラーダイアログ |

## 映像コンボ

取得後の選択肢の構成:

```
自動 (最良を選択)
ダウンロードしない
1080p h264 (mp4) [137] – 3000kbps
720p h264 (mp4) [22] – 2000kbps ★
720p vp9 (webm) [247] – 1500kbps
...
```

`★` 印は映像・音声が合わさった複合フォーマットを示します。

### 複合フォーマット選択時の動作

★印の映像フォーマットを選択すると、音声コンボが自動的に `映像に含まれます` と表示されて無効化されます。

---

## 音声リスト

multi-select 対応の `QListWidget` (4 行表示、`ExtendedSelection`)。Ctrl+クリックで個別追加、Shift+クリックで範囲選択、修飾キーなしの再クリックで選択解除。

取得後の選択肢の構成:

```
自動 (最良を選択)
ダウンロードしない
opus (webm) [251] – 129kbps [ja]
aac (m4a) [140] – 128kbps
...
```

言語コードが含まれる場合は `[ja]` などのタグが付きます。

### 排他ロジック

| 操作 | 動作 |
|---|---|
| 「自動」を選択 | 「ダウンロードしない」と各音声 ID の選択を解除 |
| 「ダウンロードしない」を選択 | 「自動」と各音声 ID の選択を解除 |
| 音声 ID を選択 | 「自動」「ダウンロードしない」の選択を解除 |
| 複合フォーマット (★) の映像選択時 | リスト全体を 1 行 (`映像に含まれます`) 表示で `setEnabled(False)` に切り替える |

### 複数音声 → MKV 自動昇格

音声 ID を 2 件以上選択した状態でキューに追加する際、出力モードが「結合」(remux のみ・音声のみ以外) のとき、その**キューアイテムの動画コンテナを `mkv` に強制昇格**します（設定の動画コンテナ値そのものは変更しません）。昇格時はステータスバーに `status_multi_audio_mkv_promoted` を表示します。

「音声のみ」モードでは複数音声選択を許容しますが、**先頭の 1 トラックのみ使用**され、それ以外は無視されます（フェーズ 1 制約）。キュー追加時に `status_multi_audio_audio_only_truncated` を表示して注意喚起します。

## 字幕リスト

複数選択可能なリストウィジェット（4 行表示）。Ctrl+クリックで個別選択、Shift+クリックで範囲選択。修飾キーなしの左クリックで選択済みの行を再クリックすると、その行のみ選択解除されます。

取得後の表示:

```
ja – 日本語 [srt, vtt]
en – English [srt, vtt]
ja – 日本語 (自動生成) [vtt]
live_chat – ライブチャット (埋め込み不可・サイドカー保存) [json]      # YouTube Live のみ
comments – ニコニコ動画コメント (埋め込み不可・サイドカー保存) [json]  # ニコニコ動画のみ
```

字幕が選択された場合のみ、字幕フォーマットコンボ（srt / vtt / best）と埋め込みチェックボックスが有効化されます。`live_chat` / `comments` は json 専用のためコンテナへの埋め込み対象外で、選択しても常にサイドカー JSON として保存されます（詳細: [ダウンロード動作 § JSON 専用字幕の扱い](../features/download-behavior.md)）。

---

## ニコニコ動画コメントグループ

字幕リストの取得結果に `comments` lang（ニコニコ動画 URL の時のみ出現）が含まれる場合に表示される `QGroupBox`。フェーズ 2 では JSON → ASS 変換のみを担当する（動画への統合はフェーズ 3）。

| ウィジェット | 既定値 | 説明 |
|---|---|---|
| コメントを ASS 字幕に変換 | OFF | ON 時に下記スピンボックスが有効化される。同時に字幕リストの `comments` 行も自動選択する |
| 画面解像度 (幅 × 高さ) | 1920 × 1080 | 出力 ASS の描画キャンバスサイズ |
| 表示時間 (秒) | 8.0 | 流れるコメント 1 件あたりの表示秒数 |
| 不透明度 | 0.8 | 0.1〜1.0 |
| フォントサイズ | 32 | 8〜128 px |

変換後の出力は `{動画ファイル名}.comments.ass` で、元の `*.comments.json` と動画ファイルに並んで保存される。バイナリ `bin/danmaku2ass[.exe]` が欠如している場合は警告ログを出すのみで他機能には影響しない。

## 出力形式ラジオボタン

| 選択肢 | 動作 |
|---|---|
| *コンテナ* に結合（デフォルト） | `merge_output_format` を設定値のコンテナで指定。サムネイル埋め込みが可能 |
| remux のみ | コンテナ再結合のみ行い、再エンコードしない。サムネイル埋め込みチェックが無効化 |
| 音声のみ (*ラベル*) | 音声トラックのみダウンロードし、`fmt_mp3` と同じ後段処理（FFmpegExtractAudio）で MP3 / FLAC に変換する。`*ラベル*` は設定の音声形式に応じて `MP3 192kbps` / `FLAC` |

コンテナ名は設定の動画コンテナに応じて変わります（例: `MP4 に結合` / `MKV に結合`）。

### 「音声のみ」選択時の挙動

- 映像コンボを無効化（選択値は保持されるがフォーマット文字列生成時には無視）。
- 字幕リスト・字幕フォーマットコンボ・字幕埋め込みチェックを無効化し、選択をクリアする。
- 音声コンボはそのまま操作可能。音声を「ダウンロードしない」にした状態でキューに追加しようとすると専用警告 (`warn_skip_audio_only`) で弾く。
- サムネイル埋め込みは MP4 結合時と同様に有効。設定の音声形式が FLAC のときは埋め込まれない（既存 `fmt_mp3` と同じ挙動）。
- メタデータ・チャプター埋め込みは有効のまま。

---

## 埋め込みオプション

| チェックボックス | デフォルト | 条件 |
|---|---|---|
| サムネイルを埋め込む | OFF | 「remux のみ」選択時は無効化される |
| メタデータを埋め込む | ON | 常に有効 |
| チャプターを埋め込む | ON | 常に有効 |

---

## フォーマット文字列生成ロジック

映像・音声の選択状態に基づき、yt-dlp に渡す `format` 文字列を生成します。音声は multi-select のため、選択数で分岐します。

| 映像 | 音声選択数 | 生成される文字列 |
|---|---|---|
| 自動 | 0 (自動) | `bestvideo+bestaudio/best` |
| 自動 | 1 | `bestvideo+{aid}` |
| 自動 | 2 以上 | `bestvideo+{aid1}+{aid2}+...` |
| 特定 ID | 0 (自動) | `{vid}+bestaudio` |
| 特定 ID | 1 | `{vid}+{aid}` |
| 特定 ID | 2 以上 | `{vid}+{aid1}+{aid2}+...` |
| 複合 (★) | — | `{vid}` のみ |
| ダウンロードしない | 1 以上 | 音声 ID を `+` で連結 (`{aid}` または `{aid1}+{aid2}+...`) |
| 特定 ID | ダウンロードしない | `{vid}` のみ |

映像・音声の**両方**を「ダウンロードしない」に設定することはできません（警告を表示）。

### 「音声のみ」モードのフォーマット文字列

映像コンボは無視され、音声リストの選択値のみが使われます。**複数音声を選んでも先頭の 1 件のみが使用**されます（フェーズ 1）。

| 音声 | 生成される文字列 |
|---|---|
| 自動 | `bestaudio/best` |
| 特定 ID (単独 / 複数) | `{audio_id}` (複数選択時は先頭) |
| ダウンロードしない | 警告 (`warn_skip_audio_only`) で弾かれ、キュー追加不可 |

## キュー追加成功 / 編集モード終了後のリセット

以下のタイミングでパネルは初期状態にリセットされます。

- オリジナル形式でキューへの追加が成功したとき（`_add_url` 即時追加 / `_on_fetch_for_add_done` の単独動画追加）
- 編集モードで「変更」が適用されたとき
- 編集モードで「キャンセル」されたとき

リセット内容:

- 映像 / 音声 / 字幕の取得結果と選択をクリアし、コンボを「自動」1 項目のみに戻して無効化
- 出力形式ラジオを「MP4 に結合」に戻す
- 埋め込みチェックをデフォルト値（サムネイル: OFF、メタデータ / チャプター: ON）に戻す
- `_fetched_title` と `_pending_restore` も破棄

---

## 編集モードでの設定復元

キューアイテムを右クリック→「形式を変更」で編集モードに入ると、前回の設定が自動的に復元されます。

- チェックボックス・ラジオボタン: **即時復元**（フォーマット取得前でも復元）
- 映像・音声・字幕の選択: **フォーマット取得後に復元**（取得が完了するまで `_pending_restore` に保持）

詳細は [ダウンロードキュー — 編集モード](../features/queue.md#編集モード) を参照。

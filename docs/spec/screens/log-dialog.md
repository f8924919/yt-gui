# ログダイアログ

[← 目次](../index.md)

> 関連実装: [yt_gui/log_dialog.py](../../arch/log_dialog.md)

## 概要

`LogDialog(QDialog)` が実装する非モーダルダイアログです。`ファイル > ログ表示` で開きます。開いたままメインウィンドウを操作できます。

**初期サイズ**: 640 × 420 px（最小: 400 × 200 px）

---

## 表示内容

ダーク背景（`#1e1e1e`）・明るいテキスト（`#d4d4d4`）・等幅フォント（Courier New, 9pt）のテキストエリアにログを表示します。

### ログに記録されるイベント

| イベント | 例 |
|---|---|
| キューへの追加 | `📥 動画タイトル  [720p (MP4 に結合)]` |
| ダウンロード開始 | `⬇️ 動画タイトル  [720p (MP4 に結合)]` |
| ダウンロード完了（ファイルごと） | `✅ 完了: filename.mp4` |
| yt-dlp のメッセージ | yt-dlp が出力する情報メッセージ |
| 警告 | `⚠️ ...` |
| エラー | `❌ エラーメッセージ` |
| キュー開始 | `▶ キュー開始` |
| 一時停止 | `⏸ 一時停止` |
| キュー完了 | `✅ キュー完了` |
| プレイリスト追加 | `✅ N 件の動画をキューに追加しました` |
| 形式変更（編集モード） | `✏️ N 件の形式を「形式名」に変更しました` |

各行は `[HH:MM:SS] メッセージ` 形式のタイムスタンプ付きです。

### yt-dlp メッセージのフィルタリング

yt-dlp からのメッセージは `_YtdlpLogger` を経由してフィルタリングされます。

- `[debug] ` で始まるデバッグメッセージはスキップ
- `[download]  45.2% of ...` などのダウンロード進捗行はスキップ
- それ以外のメッセージはログに転送

---

## スクロール動作

- **最下部にいる場合**: 新しいログが追加されると自動スクロール
- **スクロールアップ中**: 新しいログが追加されても自動スクロールしない（追いかけない）
- **ダイアログを開いた時**: 既存のログを読み込み、最下部にスクロール

---

## ボタン

| ボタン | 動作 |
|---|---|
| クリア | テキストエリアの内容を消去（`_log_entries` は消えない） |
| 閉じる | ダイアログを閉じる |

---

## ダイアログのライフサイクル

- `ファイル > ログ表示` を呼び出し時、すでに開いている場合はフォーカスを移すだけで再生成しない
- ダイアログが閉じられると `App._log_dialog` を `None` にリセット
- アプリ側の `_log_entries` は最大 2000 件を保持（2000 件超で古いものから削除）

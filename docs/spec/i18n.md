# 多言語対応

[← 目次](index.md)

> 関連実装: [yt_gui/i18n.py](../arch/i18n.md) ・ [yt_gui/locales/](../arch/locales.md)

## 概要

`i18n.py` が翻訳機能を提供します。`t(key)` 関数でキーに対応する翻訳文字列を返し、`set_language()` で言語を切り替えます。

---

## 翻訳関数

```python
from .i18n import t

label = t("btn_add")  # 日本語: "追加", English: "Add"
```

### フォールバック動作

1. 現在の言語に該当キーがあればその値を返す
2. ない場合は日本語（`"ja"`）の値を返す
3. 日本語にもない場合はキー自身を返す

---

## 言語切り替え

```python
from .i18n import set_language
set_language("en")  # または "ja"
```

言語切り替えは即座に反映されます（再起動不要）。`App._retranslate_ui()` がすべての UI テキストを再設定します。

### 論理状態と表示文字列の分離

ロジック上の意味を持つコンボ項目・リスト項目 (例: 「自動」「ダウンロードしない」) は、翻訳済み文字列ではなく **sentinel 値** を `userData` に保持して識別します。比較は `combo.currentData() == _AUTO_SENTINEL` のように行い、言語切り替え時は `setItemText` で表示文字列だけ差し替えます。これにより、新言語追加時に翻訳辞書を増やせばよく、ロジック側の変更は不要になります（実装例: [original_format_panel.md](../arch/original_format_panel.md)）。

---

## 対応言語

| 言語コード | 表示名 | ファイル |
|---|---|---|
| `ja` | 日本語 | `yt_gui/locales/ja.py` |
| `en` | English | `yt_gui/locales/en.py` |

`AVAILABLE_LANGUAGES: list[str]` に定義済みの言語コードが含まれます（`["ja", "en"]`）。

---

## 文字列辞書の構造

各言語ファイルは `STRINGS: dict[str, str]` を定義します。

テンプレート文字列はプレースホルダー `{name}` を含む場合があります。

```python
# ja.py
"dl_progress": "⬇️ ダウンロード中: {percent} | 速度: {speed} | 残り: {eta}"
"fmt_720p": "{resolution}p ({container}に結合)"
```

呼び出し側が `.format()` でプレースホルダーを埋めます。

---

## キーの分類

| プレフィックス | 対象 |
|---|---|
| `app_`, `menu_`, `label_`, `btn_` | メインウィンドウ全般 |
| `settings_`, `tab_` | 設定ダイアログ |
| `label_orig_`, `orig_` | オリジナル形式パネル |
| `fmt_` | 形式表示名 |
| `queue_`, `status_` | キュー・ステータスバー |
| `dl_` | ダウンローダー進捗 |
| `log_` | ログダイアログ |
| `tooltip_` | ツールチップ |
| `ctx_`, `edit_` | 編集モード |
| `warn_`, `err_` | 警告・エラーダイアログ |
| `lang_` | 言語名表示 |

---

## 新しい言語を追加する手順

詳細は [`docs/arch/locales.md`](../arch/locales.md) を参照してください。概要は以下の通りです。

1. `yt_gui/locales/` に `{lang_code}.py` を作成し、`STRINGS: dict[str, str]` を定義する
2. `yt_gui/i18n.py` の `_LANGUAGES` に `"{lang_code}": {lang_code}.STRINGS` を追加する
3. `yt_gui/locales/ja.py` の `lang_{lang_code}` キーに言語名を追加する
4. `yt_gui/locales/en.py` にも同様に追加する

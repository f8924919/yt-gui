# アプリ概要

[← 目次](index.md)

## 概要

yt-gui は PySide6 製のデスクトップ動画ダウンローダーです。バックエンドに [yt-dlp](https://github.com/yt-dlp/yt-dlp) を使用し、YouTube などのサイトから動画・音声をダウンロードできます。

- ダウンロードキューを持ち、複数の URL と形式をまとめて登録して一括ダウンロードできます
- Windows / macOS 向けにスタンドアロンバイナリ（PyInstaller）を提供します

---

## 対応ダウンロード形式

| 表示名 | 内容 |
|---|---|
| 最高画質（*コンテナ*に結合） | 最高品質の映像＋音声を指定コンテナにマージ |
| *N*p（*コンテナ*に結合） | 指定解像度以下の映像＋音声を指定コンテナにマージ |
| MP3（音声のみ・*N*kbps） | 音声のみを MP3 として抽出。サムネイル ID3 タグ埋め込みオプションあり |
| FLAC（音声のみ） | 音声のみをロスレス FLAC として抽出（設定で音声形式を FLAC にすると表示） |
| オリジナルの形式 | 動画から取得した映像/音声トラックを個別選択してダウンロード |

形式の詳細は [ダウンロード形式](features/download-formats.md) を参照。

---

## 主な機能

- **キュー管理**: URL と形式を登録し、まとめてダウンロード。実行中の追加・一時停止・再開に対応
- **プレイリスト自動展開**: プレイリスト URL を追加すると全エントリを自動展開してキューに登録。プレイリスト名のサブフォルダに保存
- **編集モード**: キューアイテムを右クリックして形式を変更できる。複数選択一括変更も可能
- **ツールチップ**: キューアイテムにマウスオーバーでサムネイル・タイトル・URL・形式仕様を表示
- **サムネイル埋め込み**: 最高画質・解像度指定・オリジナル形式ではサムネイルを動画ファイルに自動埋め込み。MP3 は選択制
- **字幕ダウンロード**: オリジナル形式で手動字幕・自動生成字幕を選択してダウンロード・MP4 埋め込みが可能
- **ファイル名重複回避**: 同名ファイルが既存の場合は連番サフィックス `(n)` を付与（上書きしない）
- **Cookies 対応**: ファイル指定またはブラウザからの取得（ログイン動画のダウンロードに使用）
- **多言語対応**: 日本語 / English を切り替え可能。言語変更は即座に反映（再起動不要）
- **ログ表示**: セッション中の動作ログをダイアログで確認可能
- **依存ツールチェック**: 起動時に ffmpeg・ffprobe・deno の存在を確認

## 動作環境

| 項目 | 要件 |
|---|---|
| OS | Windows 10 / 11、macOS 12（Monterey）以上 |
| Python | 3.14 以上（開発時のみ） |
| バイナリ版 | Python 不要 |

---

## バンドルされるバイナリ

| ファイル | 用途 |
|---|---|
| `deno` / `deno.exe` | yt-dlp の JavaScript ランタイム |
| `ffmpeg/ffmpeg` / `ffmpeg.exe` | 動画結合・音声変換 |
| `ffmpeg/ffprobe` / `ffprobe.exe` | 動画メタデータ取得 |
| `assets/icon.png` | アプリアイコン |

`bin/` 以下のバイナリは `scripts/download_binaries.py` で取得します（`uv run pyinstaller yt-gui.spec` 実行時に自動呼び出し）。

## プロジェクト構成（主要ファイル）

```
yt-gui/
├── yt_gui/                    # アプリ本体（Python パッケージ）
│   ├── locales/               # 言語別文字列辞書
│   ├── __init__.py            # get_resource_base()
│   ├── __main__.py            # エントリーポイント
│   ├── app.py                 # メインウィンドウ
│   ├── downloader.py          # yt-dlp ラッパー
│   ├── formats.py             # 形式定数・フォーマット文字列生成
│   ├── i18n.py                # 翻訳関数
│   ├── original_format_panel.py
│   ├── settings.py
│   ├── settings_dialog.py
│   ├── log_dialog.py
│   └── utils.py
├── bin/                       # バイナリ（自動取得・.gitignore 対象）
├── assets/icon.png
├── scripts/download_binaries.py
├── main.py                    # PyInstaller エントリーポイント
└── yt-gui.spec                # PyInstaller ビルド設定
```
